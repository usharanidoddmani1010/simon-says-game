# 🎮 Simon Says Game

A fun memory game built using **HTML, CSS, and JavaScript**. The game generates a sequence of colored buttons, and the player must remember and repeat the sequence correctly. With each successful round, the sequence becomes longer and more challenging.

---

## 📌 About the Project

The Simon Says Game is a classic memory challenge where players improve their concentration and memory skills by repeating an increasingly long sequence of colors.

This project was created to practice JavaScript concepts such as:

* DOM Manipulation
* Event Handling
* Arrays
* Functions
* Timers (`setTimeout`)
* Game Logic
* CSS Animations

## 🎯 How to Play

1. Press any key to start the game.
2. Watch carefully as one button flashes.
3. Click the same button.
4. Each new level adds one more color to the sequence.
5. Repeat the entire sequence correctly.
6. The game ends if you click the wrong button.
7. Press any key to play again.

## 🧠 Game Logic

* The game starts when the user presses any key.
* A random color is selected and added to the game sequence.
* The selected button flashes to indicate the next move.
* The player repeats the sequence by clicking the buttons.
* After each successful round:

  * The level increases.
  * A new random color is added.
* If the player clicks the wrong button:

  * The game ends.
  * The current score and highest score are displayed.
  * The player can restart by pressing any key.
